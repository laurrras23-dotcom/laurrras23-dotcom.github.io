# Delicious Monster — GitHub Pages

Esta versión conserva el diseño de `DeliciousMonster_Final_v4.html` y está preparada para GitHub Pages.

## Publicación

1. Crea un repositorio en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)`.
6. Guarda.

La página no usa PHP ni rutas locales de Windows. Las imágenes principales del diseño están incrustadas dentro del HTML, por lo que no necesitas subir una carpeta de imágenes para esta versión.
